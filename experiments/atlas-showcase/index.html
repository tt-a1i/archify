Ten ways to read a code analysis

Each page draws the same Code Analysis run in a different visual language, so we can choose what the Atlas view should feel like. Every number comes from the run; every finding can be copied as a fix prompt for an AI agent.

Data: data.js, built by build-data.mjs from a code-analysis check output with the Atlas payload builder (overlay/atlas.mjs). Point it at another run to see any repository in all ten views. Fonts load from Google Fonts and fall back to system faces offline.
