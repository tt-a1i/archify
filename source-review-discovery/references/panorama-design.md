# 系统全景与问题路径

## Overview

这份说明记录 Source Review 的局部配对视图：先从真实源码目录找到模块与关联发现，再进入单项问题核对输入、处理、输出及源码依据。全景和专用问题页继承固定版本 Archify 的 `signal-flow` 视觉、主题、相机与聚焦；审查层负责模块信息、证据语义和页面导航。

这里不建立新的全局设计系统或 token 表。视觉基础以 [上游模板](../assets/vendor/archify/assets/template.html) 为准；局部实现见 [全景样式](../assets/panorama.css)、[全景交互](../assets/panorama.js)、[问题页样式](../assets/scene.css) 与 [问题页交互](../assets/scene.js)。报告协议和 scene 约束分别见 [输出约定](output.md) 与 [证据画布](evidence-scene.md)。

## Colors

背景、面板、分隔线、正文、次要文字与悬停态直接使用上游的 `--bg`、`--panel`、`--panel-border`、`--text`、`--text-muted` 和 `--toolbar-hover`。两份局部样式不重定义这些变量，深浅色随原生主题一起变化。

全景复用上游语义颜色，但显示的是审查含义，不把节点说成前端、云或安全服务：

| 上游颜色 | 全景含义 | 判断范围 |
| --- | --- | --- |
| 玫红 `--security-stroke` | 问题位置 | 模块关联尚未修复或撤回的违反位置，且其中至少一项结论为静态确认 |
| 琥珀 `--cloud-stroke` | 待核定位置 | 存在上述违反位置关联，但没有静态确认结论 |
| 青色 `--frontend-stroke` | 关联证据 | 有发现引用该模块的证据，未落入前两类 |
| 原生 external 中性色 | 其他源码 | 没有关联发现，不表示安全或已审查 |

位置颜色不表达验证新鲜度或严重度；筛选问题列表也不重新着色地图。模块可同时关联多类记录，节点颜色和位置文案按表中顺序取优先项，具体结论仍需查看问题列表。

问题页继续使用青色共享输入、绿色已有保护、玫红偏差位置和路径的角色区分。绿色 `--backend-stroke` 也用于全景中“最小验证已复现”的文字；它不是模块健康分。证据状态同时用文字说明，不能只靠颜色传递。

## Typography

正文继承原生模板的系统无衬线字体，中文使用系统字体回退。全景标题为桌面 26px、手机 22px；问题页标题为桌面 24px、手机 21px。模块标题以 17px 为起点，宽度不足时按实测文字宽度缩小，最低 11px。正文解释以 13px 为主，路径和元信息以 11–12px 为主。

路径和源码使用 `var(--font-mono, monospace)`。当前上游模板未定义 `--font-mono`，这些局部区域实际使用 `monospace` 回退，不承诺特定字体。数量和验证值使用等宽数字；长路径允许换行，源码行保留空白并在容器内横向滚动。

## Layout

全景按源码来源分区，在每个来源的入口目录下取直接子文件或子目录作为模块，子目录汇总后代文件；提取到的入口外文件归入“其他源码”。入口没有子项时保留该入口本身。布局按每行四个模块排列，节点显示文件数、行数、关联发现及跨模块引用方向数量。目录排列和相邻位置没有执行顺序含义。

桌面全景容器上限为 1600px，主区为地图加 338px 详情栏，间隔 18px。详情栏在桌面随页面滚动保持可见，内部可滚动。宽度不超过 1100px 时改为完整地图后接详情栏；不缩窄侧栏去挤压地图。

宽度不超过 760px 时，问题列表排在前面，完整模块列表排在后面，隐藏 SVG 地图。模块列表保留所有分区与模块，点击后更新并滚动到详情；它不是只含问题模块的摘要。专用问题页在同一断点提供输入及按路径组织的节点列表，默认收起画布，仍可展开原生画布或定位选中节点。

专用问题页容器上限为 1440px；证据区将解释与源码并排，手机改为单列。影响、已检查的保护、尚未证明分别保留可读位置；验证表格在窄屏允许自身横向滚动。

## Elevation & Depth

局部容器通过原生面板色与细分隔线建立层次，不新增阴影体系。全景内的画布去掉自身边框、底色和阴影，放在地图容器中；上游 `signal-flow` 的页面氛围与节点材质继续由模板管理。

## Shapes

全景地图和详情容器使用 14px 圆角；局部按钮与输入多为 6–7px，问题页代码框和场景分组为 9px。手机模块行使用平直分隔线，保留足够点击高度。键盘焦点沿用青色描边，向外偏移 3–4px；不要另加与原生画布无关的装饰形状。

## Components

### 模块与静态引用

模块关联由证据的仓库与文件路径匹配：当前实现收集发现的检查项、反证和图节点引用；违反位置单独来自违反检查项的证据。已修复或撤回的记录不再作为问题位置，但仍可能作为关联证据出现。一项发现可关联多个模块，全局总数按发现记录计数，不能累加模块数量。

跨模块 import 按来源模块和目标模块分组。节点上的“引用 / 被引用”计数是相邻模块数，详情中的“处”是原始引用条目数；全局引用总数还包含模块内部引用。展开详情显示每条提取记录的原始文件、行号与 specifier，并可定位对端模块。没有跨模块引用时说明当前提取范围的缺口，不推断动态加载或外部依赖不存在。

地图不画 import 连线。模块内部的 import 不在跨模块引用列表中展开；文件列表只提供相对路径和行数，不是任意文件的源码浏览器。问题页中的源码摘录才是当前证据查阅入口。

### 默认问题队列

默认“已最小验证”只包含同时满足以下条件的记录：结论为 `static_confirmed`，状态为 `open` 或 `reopened`，最新验证结果为 `reproduced`，且存在已登记的验证目标，生成页面时这些目标文件的散列全部一致。它不声称未登记文件、依赖或生产环境也已核对。

“其他记录（含历史）”是上述集合以外的记录，包括待补证、待复查、未验证、已修复和已撤回等情况；“全部记录”保留所有记录。选择模块后在其关联发现内筛选，搜索匹配问题标题与影响文字。空结果只描述当前筛选，不表示模块已完成审查。每项展示后果标题、严重度、处理状态、结论或验证状态及证据入口。

### 问题路径与源码

专用问题页必须绑定报告 digest 和 finding 身份。点击节点或关系，在证据栏展开其解释、源码位置、摘录散列及采集文件状态；源码确认关系为实线，推导或待核定关系为虚线。详情保留证据切换、保护、未知和验证边界。

切换输入场景只替换已保存的输入、节点状态和验证输出，不执行目标程序。输出只来自 scene 已绑定的验证记录；缺失时显示“未验证”。历史记录及当前源码待核定须保留文字提示。原生流动和遍历高亮只是过程示意，不是线上轨迹或影响证明；暂停、动效偏好及减少动态效果继续使用原生能力。

### 配对导航与恢复

全景在打开问题链接前保存所选模块、筛选、查询、原生相机中心与缩放、页面滚动位置；键以报告 digest 隔离。返回时通过原生 `focus` 和 `view.centerAt` 恢复，保留一套相机。无已保存选择时，专用问题页的返回链接可用 finding 标识定位第一个关联违反位置模块。

恢复依赖同一浏览器会话可用的 `sessionStorage`，写入失败不会阻止导航。详情栏内部滚动位置没有保存，浏览器关闭后的持久恢复也没有实现。问题页的场景选择同样按报告 digest 存在会话内，当前并未按 finding 单独保存节点或关系选择。

### 离线包与兼容入口

`bundle` 生成全景 `index.html`、报告 `review.json`、通用证据页 `findings.html`，以及已提供 scene 的 `findings/<id>.html`。HTML 内嵌数据、样式与交互；配对导航和 JSON 下载使用相对链接，因此离线传递应保留整个输出目录。生成需要 Python 3.11+ 和 Node.js 18+；浏览页面不需要运行目标项目。

没有 scene 的发现链接到通用证据页对应的 finding，仍可返回全景。该入口保留原协议查看器，不承诺专用 scene 的节点排布和场景交互。原生渲染器拒绝布局时报告失败，不删除关系；当前实现不保证任意规模的目录图或问题图均可自动布局。生成时核验的文件状态是快照，打开离线 HTML 不会重新检查磁盘源码。

## Do's and Don'ts

- **Do** 延续原生 token、主题、相机与聚焦，用文字区分位置、证据状态、验证结果和历史状态。
- **Do** 保留真实目录、原始 import 位置、报告身份和缺失证据；把可执行的调查或修复入口放在证据之后。
- **Don't** 把无标记当作安全、把 import 当运行调用、把动画当生产追踪，或把局部验证扩写成现场后果。
- **Don't** 把被审项目的报告、截图、源码快照或验证产物放入 skill 的通用实现；局部设计说明只保留可复用行为。

消融后保留的边界：原生页面不再携带一份重复的整份报告 payload；全景和专用问题页共用一个上游渲染入口及原生相机；全景隐藏不适用的路径追踪控件。通用证据页仍需保留，因为它承担缺少 scene 的发现入口，移除它会造成可阅读证据丢失。这里不增加第二套全局 token、设计 sidecar 或独立画布运行时。
