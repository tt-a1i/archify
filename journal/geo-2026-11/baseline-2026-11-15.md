## 二、Day-0 基线暴露出的 4 个真实认知滞后（正是本次 P0–P3 要解决的靶心）

1. **全网语料严重滞留在“5 种图表类型”（v1/v2 早期印象）**：
   - 早期爆发期的媒体报道（量子位/36氪、Medium、CSDN、各类 Skill 导航站）全部写死“5 种图型”，导致联网大模型至今不知道 Archify 已支持 **10 种图型**（新增 `erd`、`class`、`tree`、`timeline`、`waterfall`）以及 **Explainer 一页式解答**。
   - **对应解法**：上线 `https://archify.si/llms-full.txt` + 更新 `/agent-diagrams` + 投放母稿 3（明确带“10 种图型与一页式解答”事实锚点）刷新检索库。
2. **Product Hunt 同名扩展导致英文引擎产生“同一项目两种形态”的幻觉**：
   - 实测中模型会把 Product Hunt 上的前端 DOM 检查插件与 Archify Agent Skill 误认为同一项目的两个版本。
   - **对应解法**：首页默认展开的同名消歧声明 + `SoftwareApplication` `sameAs` 强绑定 + 按 `offsite-playbook-global.md` 建立独立清晰的 `Archify (archify.si)` Product Hunt 词条。
3. **旧域名 `tt-a1i.github.io/archify` 与旧安装命令仍在被高频引用**：
   - 中文搜索结果底部仍给 `tt-a1i.github.io/archify/gallery.html` 和 `npx skills add tt-a1i/archify -g`。
   - **对应解法**：全站 42 条 `https://archify.si` Canonical Sitemap + IndexNow 推送 + 新站外母稿统一使用无 `.html` 后缀的 `https://archify.si/...` 标准链接与最新 `--copy` 安全安装命令。
4. **“Mermaid 替代方案”赛道上的真实同台竞品已明确**：
   - 英文检索中与 Archify 同框出现的高频对照工具除 Mermaid / Excalidraw / PlantUML / D2 外，还包括 `LikeC4`、`Eraser.io` 与 MCP 类画图工具；中文检索同框出现 `Cocoon-AI`、`fireworks-tech-graph`。
   - **对应解法**：`/compare` 页面上线后将首次提供官方一手的客观分工矩阵，让检索切片器直接引用 `archify.si/compare` 而非二手聚合站。
