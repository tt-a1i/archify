# Atlas 检查工作台：实现与验收

2026-09-12，当前分支 `codex/architecture-atlas-v1`。

桌面左侧由完整节点检查器占据，目录按需替换同一栏。没有选中节点时，显示原有章节结论；选中后显示常显的详情、关系、源码页签。图面使用更大的自适应节点文字，外层采用系统字体，减少图框和导览阴影。普通选点、清除和沿关系阅读邻点保持图的位置、大小与相机。

## 实现边界

- `atlas-navigation.mjs` 移动现有详情 DOM，保留职责、类型、上下文、tag、品牌、ID、源码版本与路径、关系预览和固定、上下游范围，以及动态节点/关系链接复制。没有第二套节点数据模型。
- 下探与规范定义引用使用明确的单一动作；普通选点不进入子图。父层关系仍只展示 manifest 明确声明的内容。
- 目录默认关闭，支持按成员图名称筛选，不承担跨图节点搜索、全文搜索或关系拓扑。
- `reader-layout.js` 先测量原有读图宽度；只有可用空间容纳至少 280px 侧栏、20px 图间距与两侧留白时才启用桌面栏。栏宽为 280–304px，不低于原来的读图预算。
- 章节卡片使用原始 DOM。桌面移入概览区；紧凑、演示和打印时回到原文档位置。没有复制卡片、画布遮挡层、强制裁剪或新图形滚动容器。
- 窄屏资料位于图后，使用稳定高度的“查看所选节点资料”入口。未选择时禁用，真实点击后保留选择并将焦点移至资料标题。窄屏允许纵向滚动；明确展开目录可改变文档流。
- 页签使用键盘方向键、Home/End 和单一 Tab 停靠点；各页签和目录独立保存滚动位置，响应式迁移保留焦点。
- `focus.js` 的 Atlas 选择路径暂停正在运行的相机过渡，保留当前画面。独立单图的原有取景、详情和清除行为不变。
- Shell 同步捕获离开时的真实状态，按每次访问保存相机、节点/关系、页签、各面板滚动、目录查询、父层披露和焦点；原生 Back/Forward 使用同一访问记录。关系行与 SVG 连线分别恢复焦点，避免同键元素歧义。
- 图的 schema、节点/关系事实和布局坐标保持原规格。Atlas 节点标题与副标题只通过现有文字拟合函数增大字号，不改连接标签和遮罩尺寸。
- 原有引导章节、路径、地图、透镜、搜索、演示与导出继续保留。浅色检查栏操作文字采用独立的较深颜色，SVG 语义配色保持原值。
