# 规范示例迁移实验：结果与收口

本轮结束。新增规范示例尚未证明能带来同质量的端到端提速；两个任务的合格对照数为 0。更明确的收获是：架构总览缺少抽象层级指导，Agent 容易把每一种 API 操作各画成一条关系，造成大量平行线。用户直接指出了这个问题。

用户反馈后的 QuickLRU 重画保留了全部 6 个角色，将 16 条逐操作连线整理为 6 条核心关系，具体条件放入分组说明。它一次通过正式 finalize，独立审查确认源码语义与默认视口可读性通过。这只是有先验知识的人工指导重画，不能计为新的独立性能样本，也不证明规则已经能稳定迁移给新 Agent。

四个首次 finalize 均失败。QuickLRU 两组首稿时间接近，不能说探索或首稿阶段已经更快。P 的修复次数较少且机器校验通过，但图片不够好读，因此不计算节省比例，也不触发反序确认试验。所有初稿到终稿的非几何投影相同；失败没有通过删语义换取机器通过。

观察到的 JSON 修改与完成 finalize 的修复不是同一指标：p-retry P 有一份坐标修改，但没有对应的新 finalize。不能将其报告成零返工。观察器最大轮询间隔约 0.114–0.133 秒，不能排除更短暂的中间状态。

## 执行偏差和可观测性

1. p-retry B 在原生 626.6 秒才检测到越界，654.1 秒出现中止事件。晚到的首稿和失败回执全部保留、全部不合格；没有声称精确在 600 秒切断。
2. p-retry P 错把准备后时长作为中断依据；派发等待约 45.95 秒，实际在原生 596.5 秒停止，比规定早约 3.5 秒。这是父任务执行偏差，不能据此判断 P 无法在 600 秒内完成。没有重跑替换该样本。
3. 冻结提取器对中止任务不提供完成时身份和耗时，评估器因而产生 identity-mismatch。另存的公开事件审计确认两者实际均为 Terra/medium；该原因不代表模型被替换。
4. p-retry P 读取了新增说明，但未观察到实际示例 JSON 或预览读取；QuickLRU P 读取了说明和 JSON，公开结果含示例标题与源码 pin。没有把“看到链接”当作“读懂示例”，也不能仅凭没有字面路径排除动态访问。
5. p-retry P 一次 labelAt 修改的公开调用/结果间隔为 196.673 秒，工具自身报告墙钟接近 0 秒。只能确认外层观测间隔异常；内部调度、结果送达、网络重试和隐藏推理不可见，尚无根因。不能全部算成代码理解或修图计算。

后处理增加 `audit_public.py`，修正 `summarize.py` 对中止任务读取记录的缺失处理；没有改变冻结作者输入或资格门槛。原始中止记录仍在。4 项针对性测试通过。

## 质量审查

7 份首稿/终稿盲化案例由 Luna 与 Terra 独立审查。QuickLRU 四份语义通过；p-retry 三份遗漏了 `index.js:124-139` 的提前耗尽时间分支：仍调用 `onFailedAttempt({retryDelay: 0})`，跳过 consume/retry hooks 后拒绝。P 还没有明确说明 AbortSignal 对已运行 input 的取消限制。

Terra 最初漏判 p-retry，针对冻结检查点复核后改为失败，原报告与更正均保留。QuickLRU P 的视觉判断有分歧：Luna 通过、Terra 失败。父任务查看四张实际截图后采纳失败；用户也明确反馈“怎么那么多线”。1440 默认视口下多条 API 条件标签很小，平行线使核心关系难以阅读。其他失败案例没有合格截图，视觉状态保留为未知。

## 用户反馈后的重画

`benchmarks/example-transfer-20260921/readability-revision/build.mjs` 生成一份新的中文说明图，保留调用方、控制器、当前代、旧代、有效期检查和外部回调。set 两种条件、整代轮换、get 晋升、has/peek 不晋升、过期与主动删除的区别及计数规则留在分组卡片和引导说明中。没有把数据库图标解释为持久或远程存储。

该重画属于用户要求的表达方式调整，不是冻结试验中的几何修复；不替换原失败图片和任何指标。源码与四张实际截图的独立复核结果为 semantic pass / perceptual pass。首次 finalize 的四项门槛全部通过。截图命令曾误用不支持的 `--widths`，改为已有的默认采集命令后完成；没有修改产物规避验收。

可复现 JSON、HTML、截图、回执与独立审查保存在证据归档 `benchmarks/example-transfer-20260921/evidence/records.tar.gz` 的 `readability-revision/` 下。`archive-manifest.json` 包含归档及每个成员的 SHA-256，并逐成员回读验证。

## 收获与边界

规范示例有价值，但“放一个链接”不足以保证 Agent 使用它，更不能保证它学会控制表达层级。下一步规则候选应说明哪些是架构关系，哪些是同一关系上的操作条件，并要求每个被移出的条件有明确的可见承载位置。具体候选见 `readability-revision/authoring-rule-proposal.md`；尚未作为正式 Skill 规则安装或推广。

这轮已收口，没有继续新实验。原工作区状态和差异哈希、正式包、冻结输入以及三个 live 安装均与起点一致。只有本地研究提交；没有推送、安装或远程状态检查。保存完整失败样本，不宣称性能收益。
