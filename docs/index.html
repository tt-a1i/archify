Quick Start

Up and running
in three steps.

One checked Skill for Cursor, Claude Code, Codex, and OpenCode. Their switcher generates exact commands; for Raven, extract archify.zip into ~/.raven/workspace/skills, which yields ~/.raven/workspace/skills/archify.

1

Install in one command

Run npx skills add tt-a1i/archify -g, or open the agent-aware quick start for an exact Cursor, Codex, Claude Code, or OpenCode command. Raven is not a switcher target; for a manual ZIP install, extract archify.zip into ~/.raven/workspace/skills, which yields ~/.raven/workspace/skills/archify.

2

Describe your system

Describe components, connections, and cloud services — or ask your agent to analyze the repository first.

3

Ask your agent to draw it

Tell your agent to use Archify. It generates a self-contained HTML file you can open in any browser and refine in chat.
