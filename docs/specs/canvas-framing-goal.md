# Goal：稳定图形尺寸、首屏完整取景与镜头保持

状态：**已完成。G1–G4 与 C1–C16 验收通过，消融及最终产物已归档。** 进展及逐项证据见[实施记录](../reviews/canvas-framing-goal-20260923.md)。

决策来源：2026-09-23，用户指出固定画布版本初始图形过大、偏离原有观感，认可“首屏看全貌，放大读细节，操作后保持镜头”的方案，要求明确边界和验收标准。

实施基线：`codex/labs-infinite-canvas`，HEAD `3791eb59840e10cd5766871e21b723fa2358b4ea`，叠加当前工作区已完成的画布修复。开始实施时记录实际 HEAD、工作区差异及权威源码哈希，保留已有改动。

## 目标与成功定义

在固定桌面画布中，首次打开普通图就能看到完整结构；小图不因窗口宽而被自动放大；大图先给出全貌，用户通过现有缩放、章节和搜索深入阅读。用户操作后，侧栏开关和窗口变化不再偷偷改变图形大小或丢失阅读位置。

画布面积、图形的基准尺寸、相机取景分别负责各自的行为。图形的节点、文字、配色、连线、分组与章节不因窗口布局调整而重新编排。

成功不能只以无滚动条、相机 scale 不变或测试数量判断。必须同时证明首屏完整、实际显示尺寸稳定、阅读位置保持，以及同输入截图的视觉效果符合本 Goal。

## 与已有 Goal 的关系

本 Goal 修正[固定桌面画布 Goal](desktop-fixed-canvas-goal.md)的首屏与尺寸约定，并保留其无页面滚动、独立说明侧栏、文字默认完整显示和兼容性要求。旧验收通过是历史实现证据，不能视作本轮观感合格。

| 原约定 | 本轮约定 |
| --- | --- |
| 普通初始视图保持 100%，允许只看到局部 | 无明确定位链接时，首次完整取景；小图最多以 100% 显示 |
| 100% 相对于随容器宽度变化的默认 SVG 尺寸 | 固定画布中使用稳定基准；同一倍率下，窗口／侧栏不改变实际图形尺寸 |
| 手动视图只检查相机 scale 数值不变 | 同时检查有效显示比例、节点屏幕尺寸和阅读位置 |
| 全图适配最大可达到 400% | 固定画布的首次取景与“全图”最多 100%；手动放大上限仍为 400% |
| 使用较早的 private-project 简化规格作主要效果对照 | 使用已找到的完整 private-project 规格作同输入对照，简化规格仅可作为额外无卡片回归 |

百分比按钮、`0`、`reset()` 和旧 `fit()` 的重置入口保留，不能把它们偷偷改成“全图”。固定画布中 100% 的视觉基准发生明确变化，但重置仍恢复 `{scale:1,x:0,y:0}`；它不等于首次完整取景。按钮名称／提示应清楚表达“重置至 100%”，已有“全图”负责完整居中。

上述变化仅覆盖普通固定桌面模式。演示、embed、窄屏／短窗口、打印与规范导出沿用已有合同；共享代码必须做模式隔离和兼容验证。

## 行为合同

### 1. 图形基准与取景范围

- 固定画布的 100% 定义为原始 SVG 一个用户坐标单位对应一个 CSS px；以完整根 viewBox 为坐标范围，不混同设备物理像素、DPR 或浏览器页面缩放。已有元素内部变换和作者字体保持。
- 同一图形在固定模式的 50%、100%、200% 下，有效显示比例分别是这一基准的 0.5、1、2 倍。容器可以占满窗口，但不能继续通过 `width:100%` 拉伸图形基准，再用第二层相机缩放补偿。
- 不把任意节点包围盒作为全图范围。原 viewBox 内的分组、箭头文字、图例、时序轴等都必须纳入，原始留白也保留。无限网格、工具和交互装饰不纳入。
- 可用矩形沿用真实可见画布区域：扣除布局内边距、导航保留区和已打开侧栏的宽度，再留四边 16 CSS px 的安全距离。不能通过遮住边缘或缩小作者字号满足包含检查。

### 2. 首次打开与“全图”

在固定画布中，用可用矩形宽高 W/H 与原 viewBox 宽高 Vw/Vh 计算：

`s = min(1, (W - 32) / Vw, (H - 32) / Vh)`

W/H 在公式中尚未扣除四边安全距离。以这一正有限比例居中完整 viewBox。小图保留 100% 和自然留白，大图允许低于 25%，后续放大必须连续。无有效尺寸时等待已有布局就绪信号，不写入零比例、NaN 或 Infinity，也不启动空闲轮询。

- 首次没有明确定位目标时进入全图适配状态，首次适配不播放缩放动画。不能先可见地显示被截断的 100% 大图，再明显缩小。
- 加载时已有合法节点／章节／分享时刻目标，先按原合同解析目标，由显式定位接管；迟到的首次适配、字体回调或 resize 不能覆盖它。无效目标沿用原错误／回退处理，最终回到正常完整取景。
- 用户主动点击“全图”进入相同的居中规则，并按现有接管规则结束旧手势／自动导航；重复执行幂等。手动放大到 100% 以上仍有效。
- 字体或布局就绪后的必要纠正只作用于仍由自动适配管理的视图。用户一旦操作，不得再用“初始化尚未完成”为由覆盖镜头。

### 3. 用户操作与尺寸变化

| 当前意图 | 侧栏开关／固定模式内 resize 后 |
| --- | --- |
| 首次取景或用户刚选择“全图” | 按新可用矩形重新完整适配，仍不超过 100% |
| 用户已平移、缩放或重置至 100% | 保持实际缩放；以变化前可用画布中心对应的图内坐标作为阅读锚点，将其放在变化后可用画布中心 |
| 章节、节点或分享目标正在语义定位 | 保留既有语义目标与接管合同，不被默认全图覆盖；用户手动操作后转为手动意图 |

- 原始 translate 数值不是阅读位置；可用区域或 SVG 原点变化时允许调整 translate，以保持同一图内锚点。手势中的 resize 应先按现有规则结束或重基准本次操作，不留下拖动／定时器尾部覆盖新状态。
- 桌面断点往返仍按原合同恢复文档模式。返回固定模式时保留最近有效的用户意图；若回退期间没有用户操作，恢复进入回退前的手动比例与阅读锚点；若有明确操作，以最新操作为准。
- 不跨刷新保存镜头，不增加视图历史；单次页面会话内的必要状态由现有相机拥有。禁止 Reader 和 Camera 各自保存一套独立镜头状态。
- 小地图、倍率提示、搜索、章节和详情的坐标换算必须使用同一实际变换。不能只修主图而留下小地图定位或指针缩放偏移。

### 4. 文字与视觉边界

- 所有原有节点标题、副标题、tag 和连线文字默认绘制，继续覆盖低倍率，不恢复悬停显示或语义缩放隐藏。
- 完整全貌不等于所有标签在一屏都可读。大图总览允许文字变小；在 100% 阅读倍率必须保留原文字和字号。普通图首屏与正常阅读倍率分别审阅，不以其中一个代替另一个。
- 节点样式、配色、分组、章节和说明内容保持。侧栏不搬回页面下方；只因必要尺寸修正触及容器 CSS，不顺带改整套界面。
- 本轮不优化网格密度、阴影、圆角、工具栏造型，不新增缩放菜单、手动“阅读／画布”模式或“适应选中”入口。这些独立候选在本轮通过后再评估。

1. **固定证据。** 保存当前工作区及上述完整输入，建立 C1 清单；复现原来的首屏截断和侧栏／resize 导致的实际比例漂移。保留旧实现失败证据，不只修改预期值。
