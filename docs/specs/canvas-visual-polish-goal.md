# Goal：画布网格、阴影、工具栏与左下角固定图例

状态：**实施完成。G1–G4、A1–A17、视觉审阅、消融与产物同步的结果见[实施记录](../reviews/canvas-visual-polish-goal-20260923.md)。** 本文保留原验收定义；改动位于 `codex/canvas-visual-polish` 本地工作区，尚未提交或推送。

决策来源：用户选择网格、阴影和工具栏三项美化，并增加“图例像工具栏一样固定在左下角”，认可方案后要求确定边界、验收测试并整理 Goal。

规划基线：`codex/labs-infinite-canvas`，`018378126c5d09085ef79afcd28434d388e8a2bf`（PR #531 修复提交）。本轮规划开始时工作区干净。实施开始时重新核对 HEAD、工作区、输入和基线产物，保留其他已有改动；不得用带候选改动的工作区冒充基线。

## 目标与成功定义

让背景网格在缩小时保持疏朗、操作浮层轻且清楚、工具栏容易辨认；让图例在桌面阅读时始终位于可见画布左下角，平移和缩放不会把它带走或缩成不可读的小字。

本轮改善 Viewer 的背景与操作界面。沿用[稳定取景 Goal](canvas-framing-goal.md)的图形尺寸、首次完整取景、手动阅读锚点和文字完整展示合同，以及[固定画布 Goal](desktop-fixed-canvas-goal.md)未被其替代的说明侧栏、输入、打印与导出合同。

成功须同时满足实际操作、几何测量和同输入视觉对比；测试通过不能替代“网格不抢眼、控件可辨、图例固定且可读”的图像审阅。

## G1：随缩放稀疏化的网格

- 100% 附近保留现有 24px 细网格和 120px 主网格的空间参照，整体降低背景存在感。网格是装饰，不编码业务数据。
- 随缩放切换嵌套网格层级；稳定倍率下主要可见的基础点阵间距目标为 24–48 CSS px，边界允许 1px 测量误差。主网格可更疏；过渡中淡出的旧层不受此区间约束。
- 细密层在切换前淡出，避免低倍率仍绘制成密集噪点。透明度由当前倍率决定，切换使用共同图内原点，不单独按屏幕坐标滚动背景。具体透明度经同输入对照确定并记录。
- 点大小保持适合屏幕阅读的尺度，不随倍率膨胀成大斑点；不得以放大节点、提高图形对比度补偿网格问题。
- 更新并入现有镜头帧；固定倍率平移仅更新网格位置。静止时没有网格动画、计时轮询或持续 DOM 写入。减少动态效果模式也不能新增时间驱动的网格过渡。
- 背景不进入规范 SVG、图片或打印；原先不显示无限网格的模式继续如此。

## G2：阴影层次

| 对象 | 设计目标 |
| --- | --- |
| 画布、固定说明侧栏 | 主要用细边框和底色分区，减轻大范围外阴影 |
| 右下角导航条、固定图例、浮动小地图和详情 | 共用轻柔浮层层次，边界清楚，背景图形不干扰文字 |
| 当前展开的菜单与搜索面板 | 高于常驻浮层，靠适度阴影与边框表达前后关系 |
| 顶部按钮 | 弱化各自阴影，靠底色、边框、悬停和选中状态辨认 |

只修改这些 Viewer 容器的阴影／必要底色与边框；不改 SVG 节点 glow/filter、路径强调或章节动画。复用现有主题／预设变量；若需要集中少量阴影值，限定为上述具体层次，不引入新的主题系统。最终数值和浅深主题截图在实施报告中记录。

## G3：工具栏视觉与输入合同

- 顶部操作区保持已有按钮顺序、文字、功能及布局位置。已有较大的点击区域不缩小。
- 右下角导航条保留顺序，以轻分隔与留白表达“路径／地图／透镜”“搜索／帮助”“全图／缩放”三组；不新增重复入口或更多菜单。
- 桌面导航文字目标 11–12 CSS px，图标约 14px；按钮实际命中区域至少 32×32px，长文字按钮可更宽。按本地化长度调整，不能把西班牙语等文案压成不可读小字。
- 保留可辨认的正常、悬停、选中、禁用、键盘焦点状态；非禁用文字对实际底色对比度 ≥4.5:1，操作图标与焦点指示 ≥3:1。选中状态同时有底色／边框等形态提示，不只改文字颜色。
- 倍率显示预留宽度，覆盖低于 1%、100%、400% 及已有语义指示文案；缩放本身不造成相邻按钮来回移动。
- 背景有足够遮蔽性；保留主题色调，控制图形透过造成的阅读干扰。增大的文字或图标不得遮挡图例、图形安全区域或现有面板。
- 保留当前键盘、鼠标、焦点归属与输入接管规则；控件上的 Space、方向键、滚轮等按控件职责处理，不意外平移画布。

## G4：左下角固定图例

### 内容与状态

- 图例由当前渲染产物的权威图例条目投影到 Viewer；原名称、顺序、颜色、图形／线型、作者显隐选择全部保留。`meta.legend` 的 hidden（无图例）/auto/all 与条目显隐子集规则仍由原合同决定，不能在 Viewer 补造原本没有的条目。
- 保留五类图的区别：时序图的线型说明仍是说明；数据流图只有已有精确节点类型语义的条目可交互。不得把所有条目都改成按钮，或给线型图例臆造节点数量。
- 原来具有交互能力的条目继续支持已有数量、零数量状态、预览、选择与 Semantic Lens 联动；优先级、关闭和焦点返回行为沿用原合同。普通名称始终可见，不改为悬停才显示。
- 图例内容、统计与选择只有一个权威来源；复用 Semantic Lens 的状态。固定图例与原图例不能分别维护互相漂移的选择列表。
- 固定版本准备成功后，原 SVG 图例才在该模式下隐藏并退出辅助技术／键盘导航；失败时保留原图例。禁止出现两份可操作图例、重复 DOM ID、隐藏控件仍获得焦点，或初始化短暂两份可见。
- 切回原模式时还原原图例；在图例中发生模式切换时，焦点转到对应可见条目或图例入口，不能丢到已隐藏节点。JavaScript 不可用时原静态图例可读。

### 停靠与空间分配

- 固定在**当前可见画布容器左下角**，不固定到整个浏览器左下角，不跟随 SVG 相机变换。与右侧导航共享现有底部控件区域和安全边距。
- 停靠边距初值沿用 16 CSS px。侧栏开关、窗口变化和主题／字体变化后，以剩余画布边界定位；图例字号不随图内倍率变化。
- 宽度充足时完整横排；不足时最多两行。若两行仍不能完整展示，折叠为明确的“图例（条目数）”按钮，点击／键盘激活展开完整列表。禁止截断名称后只靠 tooltip 补全文字。
- 完整列表向画布内展开，最大高度不超过 320px 且不超过画布高度的 50%，内部允许纵向滚动；不增加整页或画布原生滚动条。超长单项可换行。Esc 关闭并返回入口焦点，最后一项可通过键盘与滚动访问。
- 两端控件之间至少 8px 间隔，互不重叠。底部常驻区域占用纳入现有布局的可用矩形；自动全图／章节取景避开该区域。手动镜头允许用户把图形拖到控件背后，但不得被强制拉回或改比例。
- 展开的图例列表是临时覆盖层，不触发相机缩放／重新取景。小地图、节点详情、透镜等面板复用现有避让协调，至少保持入口、关闭按钮和当前操作目标可达；不新增任意多面板全局布局求解器。
- 布局只随真实尺寸／内容变化失效；图例不参与全图包围盒。原 `viewBox`、节点位置和原图例留白保留，不自动裁剪 SVG。

### 打印与导出

普通桌面只显示固定版；回退／演示／embed 使用原版；打印和规范 SVG／PNG／JPEG／WebP 使用原始图例。导出前后活页面的镜头、图例选择、焦点和展开状态保持。

导出不得复制固定工具外壳，也不得因隐藏原图例的 class、style 或属性遗留而丢失图例。原图例文字、色块、线型与范围保持，只出现一份。共享导出克隆／清理路径若发生变化，追加 WebM 实际解码／站点集成门禁，确认无遮挡、重复和运行时状态泄漏。

## 明确不包含

本轮不新增返回视野／历史栈、缩放菜单、适应选中、Outliner、节点编辑、触屏多指手势、工具栏自动隐藏、图例自由拖动、跨刷新偏好保存或新的视觉 preset。不改滚轮方向、快捷键、初始镜头规则、schema、作者内容、版本和发布身份。

标题区、章节导航、节点、箭头、说明正文和图形排版保持。新增底部图例或工具尺寸可能改变实际可用矩形；这是允许的 UI 占用变化，必须测量并通过现有完整取景及阅读锚点合同，不能要求相机 translate 在所有窗口下字节不变。
