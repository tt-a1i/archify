# Goal：完善 XMind 类画布的平移、全图适配与小地图反馈

状态：**已完成本地实现与验收**。G1–G3、A1–A12 已交付；定向浏览器 34 项、完整浏览器门禁 252 项通过，最终完整测试 2266 通过／0 失败／12 条件跳过；生成产物、消融和感知审阅已完成。详见[实施与验收记录](../reviews/infinite-canvas-goal-20260922.md)。

实施基线：`codex/labs-infinite-canvas`，提交 `3791eb59840e10cd5766871e21b723fa2358b4ea` **加当前工作区上一轮已验证的修复**。开始实施时重新记录提交与工作区差异，保留已有改动。

## 目标与范围

让用户能够发现平移方式，在自由移动和放大后恢复全图，并在移动过程中通过小地图持续确认位置。所有能力服务于现有架构、流程、时序、数据流、生命周期五类图，保留各自的布局与语义。

本轮只交付三个能力：

| 能力 | 本轮交付 | 边界 |
| --- | --- | --- |
| 平移入口 | 保留右键，增加空格＋左键和中键拖动；抓手光标与帮助提示 | 普通左键仍用于节点与控件操作；保持现有滚轮和方向键行为 |
| 适应全部 | 独立入口，按当前可见画布适配完整图形；支持极长、极宽图 | 原百分比按钮与 `0` 继续重置默认视图；首版不扩展缩放菜单或“适应选中” |
| 小地图反馈 | 手势中实时更新视口框及缩放百分比；小地图平移保持比例 | 面板排版与节点高亮扫描在操作结束后同步，节点点击继续语义聚焦 |

主要适用范围为桌面鼠标和触控板，以及现有演示模式。窄屏宽图的原生横向滚动、embed 展示、打印、导出保留现有行为；新入口在不适用的模式中隐藏或禁用，并提供符合当前语言的说明。

## 交互约定

### G1：可发现的平移

- 画布中的右键、空格＋左键、中键使用同一套平移行为。空格仅在画布拥有键盘焦点时启用；提示说明先点击或 Tab 进入画布。
- 按住空格显示 grab，开始拖动后显示 grabbing；松开按钮、松开空格、失去焦点、取消指针或失去捕获时，结束本次拖动并保留当前位置。
- 新手势遵守现有重置和镜头接管规则。只为实现新增手势调整必要入口；滚轮与所有手势的整体接管重构留到后续。
- 输入框、可编辑内容、按钮、导航栏及其他交互面板保留自己的按键和鼠标行为。普通左键点击节点不变；完成画布拖动后不会意外激活节点。
- 帮助入口列出右键／空格＋左键／中键平移、滚轮平移、Ctrl/Cmd＋滚轮缩放、方向键导航及重置方式。新文案走现有本地化机制，焦点和辅助技术名称完整。

### G2：真正的“适应全部”

- 提供独立、可键盘访问的“适应全部”按钮，复用现有导航条。原百分比按钮、`0` 与 `reset()` 仍恢复 `{scale:1,x:0,y:0}`；100% 表示相对默认视图的比例，不宣称原始像素 1:1。
- 新增清晰命名的全图适配操作。现有 `fit()` 是 reset 别名，本轮保留其兼容行为，避免静默改变既有调用者。
- 全图范围以原始 SVG `viewBox` 为权威，覆盖原图中的节点、连线、分组、标题、时序轴与标签；不将无限背景网格、焦点装饰或小地图纳入计算。禁止仅按节点边界适配而遗漏其他图形。
- 可用矩形是画布裁剪区域与浏览器可见区域的交集，扣除容器内边距及已保留的导航空间，并在内容四周额外保留 16 CSS px。浮动详情卡和小地图继续使用现有避让机制，本轮不求解任意遮挡区域。
- 在可用矩形内等比缩放、居中完整图形；最大比例沿用 400%。全图适配可以低于 25%，缩放状态、按钮和指针缩放必须支持这一结果，不得随后突然跳回 25% 或 100%。低于 1% 时显示可理解的比例，不能显示成 0%。
- 正比例和有限数值是硬约束。有效全图比例由内容和视口计算，不用固定 25% 截断；普通图的手动缩放下限仍为 25%，需要更小比例才能适配的图允许缩至其全图比例。
- 用户主动执行适配后进入全图适配状态；窗口尺寸变化时保持全图可见。用户开始平移或缩放后退出该状态，后续尺寸变化不能擅自重新适配或跳变比例。
- 执行适配时取消旧手势、旧镜头动画和正在播放的自动导航对相机的控制，使用既有接管规则。重复执行得到同一结果；空内容、无效边界或无可用空间时安全退出，不写入 NaN、Infinity 或零比例。

### G3：实时且保持比例的小地图

- 对主画布的鼠标拖动、滚轮平移／缩放和方向键平移，小地图视口框最多落后实际镜头两帧；缩放百分比同步更新。显示数值未改变时不重复写文案。
- 小地图拖动、空白处点击定位和方向键导航只改变位置，保留当前缩放，包括 50%、100%、200% 和低于 25% 的适配状态。
- 点击小地图中的节点仍走现有语义聚焦，可按现有规则改变比例。拖动小地图面板标题栏仍只移动面板。
- 交互帧仅更新镜头、网格、视口框及必要的比例文字；面板避让、全节点高亮扫描与其他完整布局同步延后到操作结束。视口尺寸变化引发的必要几何失效处理不属于重复稳态排版。
- 小地图关闭时不为它持续安排帧或更新 DOM。操作结束后镜头、裁剪、视口框、控件和节点状态最终一致，所有临时动画与手势标记正常释放。

## 验收标准

以下均须给出实际结果；未运行或跳过的检查不能记为通过。

| 编号 | 场景 | 通过条件 |
| --- | --- | --- |
| A1 | 三种鼠标拖动分别向四个方向移动 | 位移方向与拖动一致；结束后不再移动；普通节点点击不变 |
| A2 | 空格输入、按钮激活、Tab 进出画布、拖动取消 | 输入与控件行为保留；画布可从键盘进入；无残留抓手、拖拽状态或误点击 |
| A3 | 新拖动进行中执行重置或全图适配 | 新命令最终位置稳定，旧 pointermove、计时器或 rAF 不覆盖结果 |
| A4 | 五类代表图从任意偏移和比例执行适配 | 原始内容范围完全位于定义的可用矩形内，误差不超过 2 CSS px；居中且保留规定边距 |
| A5 | 300 节点长图及一个极宽图，适配比例低于 25% | 能完整适配；随后放大连续、指针锚点稳定；从适配比例用小地图平移不改变比例 |
| A6 | 适配后改窗口尺寸，再手动平移后改尺寸 | 前者保持完整可见；后者不被自动拉回全图；重复适配幂等 |
| A7 | 适配后点击百分比或按 `0` | 恢复原默认视图；既有 reset/fit 调用合同保持；无非法比例或坐标 |
| A8 | 连续 2 秒平移或缩放，小地图打开 | 视口框和百分比在两帧内反映相机；结束后与实际镜头一致 |
| A9 | 50%、100%、200% 及低于 25% 时操作小地图 | 拖动／空白定位／方向键保持比例，误差不超过 1e-6；点节点语义聚焦、标题栏移动仍有效 |
| A10 | 对稳定视口中的连续手势计数 | 完整面板避让和全节点扫描不随手势帧数增长；结束后完成一次合并同步；关闭小地图后无持续更新 |
| A11 | 五类图的兼容路径 | 暗／亮主题、普通／演示、窄屏宽图、embed、减少动态效果、打印和导出保留既有合同 |
| A12 | 原始 JSON、导出 SVG 与运行时状态检查 | 拓扑、ID、连线和显式几何不变；运行时手势、镜头、网格和小地图状态不污染规范导出 |

代表输入优先复用当前五类 bundled 示例、300 节点 workflow fixture，以及已有极宽 sequence/dataflow fixture。只有既有输入无法覆盖边界时才新增最小测试数据。至少在 1440×900、2048×1320 桌面视口验证，并沿用现有窄屏回归。

## 执行与完成条件

1. **固定基线。** 记录当前提交、工作区修复、输入与视口；先检查现有 API 和调用者，逐项映射 A1–A12。完成条件是每项验收有明确测试或观察入口。
2. **按 G1 → G2 → G3 实现。** 先补能暴露差异的行为回归，再修改 `viewer/` 权威源码。每步完成后通过对应检查，再进入下一步。
3. **验证与消融。** 通过适用的浏览器回归后，逐一移除本轮可疑的缓存、状态或抽象，重跑相关验收；通过则保留删除，失败则恢复并记录原因。合并后的验收覆盖须包含上一轮修复。
4. **集成交付。** 遵守 [CONTRIBUTING.md](../../CONTRIBUTING.md) 和 [REVIEWING.md](../../REVIEWING.md)，从最终源码生成受影响产物，完成共享 Viewer 变更要求的完整测试、真实浏览器门禁和产物验证。复用证据要标明版本与覆盖范围。
5. **完成报告。** 交付可审阅的本地改动，列出 A1–A12 的结果、未解决项、代表性截图／操作证据、同步产物及消融结果。只有功能、验收、产物同步均完成才可宣称实现完成。

本轮实现完成的定义是本地变更可审阅、证据齐全；提交、推送、PR、合并和 live Archify 安装不包含在此 Goal 中。
