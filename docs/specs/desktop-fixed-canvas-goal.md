## 目标与成功定义

在适用的桌面窗口中，页面保持在固定视口内，画布占据工具区域下方的剩余空间。用户通过相机平移、缩放和“全图”浏览图形，通过独立说明面板阅读卡片；不会因鼠标离开画布而滚动整页，也不会为了取消滚动而丢失内容或入口。

这是一次共享 Viewer 默认布局调整，覆盖架构、流程、时序、数据流、生命周期五类图。不要求作者重新布局、删减内容、修改 schema 或重新指定 viewBox 来适应新界面。

本 Goal 在适用桌面范围内取代[上一轮 Goal](infinite-canvas-xmind-goal.md)及现有 Reader 的“保留普通页面文档流”约定；上一轮 G1–G3 的平移、适配、小地图语义继续有效。旧测试中“桌面长卡片允许撑高页面”的断言须按新范围迁移，不能简单删除相关内容可达性检查。窄屏、短窗口、embed、打印的兼容约定不被此变更覆盖。

## 交付范围与边界

| 项目 | 本轮交付 | 保留边界 |
| --- | --- | --- |
| G1 固定桌面画布 | 普通桌面视图固定在窗口内；标题、工具栏与章节入口可达，画布填满剩余区域；无页面横／纵向滚动 | 图形可以超出画布视野，由相机浏览；不引入画布自身的原生滚动条 |
| G2 独立说明面板 | 原图下方说明卡片转入“图示说明”侧栏，默认关闭；内容过长时仅面板内部滚动 | 保留所有卡片标题、正文、列表、链接和顺序；节点详情与说明卡片是不同内容 |
| G3 输入与布局协调 | 画布、说明面板和现有交互面板分别接管自身输入；尺寸变化后更新相机可用区域与导航／小地图布局 | 不重写手势系统、面板管理器、动画引擎或导出流水线 |
| G4 完整文字展示 | 所有原本属于图形的节点标题、副标题、标签／注释、连线文字默认显示；不再因缩放较小而隐藏或依赖悬停恢复 | 不把详情面板中的源码、元数据和关系列表复制到图上；完整图内文字与补充详情分开 |

适用模式优先级与断点：

1. 打印使用打印布局，不受固定高度或折叠状态约束。
2. `embed` 保留现有嵌入布局与输入合同；和演示参数同时出现时仍由 embed 优先。
3. 演示模式沿用现有独立布局，不通过自动进入演示模式实现本功能。
4. 普通视图在 **CSS 视口宽度 ≥1024px 且高度 ≥600px** 时启用固定画布，与图形宽高比无关。断点使用 CSS 视口，不推测设备型号；浏览器缩放改变 CSS 视口时同样适用。
5. 宽度或高度低于上述边界时保留文档式布局及现有窄屏宽图横向浏览；说明卡片恢复原位置，允许必要的页面滚动。尤其不在小窗口中隐藏内容以维持“无滚动”的表象。

断点和模式切换必须可逆：移除不适用的固定高度、滚动限制、隐藏和焦点状态，不留下空白侧栏、不可见焦点或重复卡片。

## 交互约定

### G1：固定视口与相机

- 外层布局按视口分配真实尺寸，画布位于剩余空间内；必要的工具栏换行计入高度预算。长标题／副标题可紧凑展示，但完整文本必须能通过可访问的说明入口读取。
- 不用隐藏 scrollbar 样式、透明滚动条、全局阻止滚轮事件或单独给 body 加 `overflow:hidden` 作为完成方案。只有内容与工具均有可达布局后，才能限制外层溢出。
- 不拉伸 SVG、不修改原始 viewBox、节点坐标、拓扑或文本大小来掩盖页面溢出。普通初始视图不强制进入 fit-all；默认比例可以显示局部，完整范围必须能通过平移和“全图”到达。
- 普通滚轮／触控板在画布内平移；Ctrl/Cmd＋滚轮保持现有缩放语义；右键、空格＋左键、中键和方向键保留上一轮归属规则。画布外的工具条／标题区域不驱动画布或页面滚动。
- 百分比按钮、`0`、`reset()`、旧 `fit()` 仍恢复 `{scale:1,x:0,y:0}`；不将“默认”悄悄改为 fit-all。
- 窗口尺寸或侧栏开关改变可用空间时，fit-all 状态重新适配；手动视图保持缩放，不被强制拉回默认／全图。导航、小地图和浮动面板按新矩形重新布局。

### G2：说明面板与内容可达性

- 新增可键盘到达的“图示说明”按钮。面板为非模态侧栏，拥有独立布局宽度，开启时从画布可用宽度中扣除；不覆盖画布导航或工具栏。关闭后画布收回空间。
- 首次进入固定画布默认关闭；没有卡片且没有被紧凑展示的标题说明时不显示空入口。刷新不必保留开关状态。
- 打开后焦点进入有名称的说明区域；关闭按钮及面板内 Escape 关闭面板并把焦点还给入口。Tab 可正常离开，不设焦点陷阱。Escape 不抢占面板内其他已展开控件自己的关闭行为。
- 长内容可滚到最后一条，链接可聚焦、文字可选择／复制；长 URL 等内容可换行，不迫使页面横向溢出。滚到面板顶端／底端后继续滚动，不传递为画布平移或页面滚动。
- 卡片只有一份内容权威；不得复制出重复 ID、重复焦点目标或两份独立状态。进入窄屏／短窗口／打印时显示完整原内容。
- 现有节点详情、搜索、关系、导出菜单等保留各自的内部滚动和键盘行为；它们不被并入本次说明面板。新名称、按钮状态和辅助说明覆盖现有 en、zh-CN、es 本地化。

### G3：兼容与资源边界

- 桌面普通模式与演示模式保持不同入口和状态。切换演示前后，节点选择、主题、图形语义和现有相机切换合同保留；说明内容按演示原合同隐藏，退出后重新可达。
- 打印输出包含完整图形和原有说明卡片，允许分页；无固定视口裁剪、面板滚动区截断或仅打印当前镜头局部。
- SVG／图片／WebM 的规范图形导出保留现有范围和语义；本次新增的侧栏、布局属性及相机装饰不进入规范 SVG。卡片不因本次布局调整被额外塞入图形导出。
- 新布局仅在尺寸、模式、可见内容等必要变化时测量。连续平移／缩放不增加逐帧完整排版、全节点扫描或空闲轮询；复用既有 Reader／Chrome Layout 稳定机制，避免两个模块相互反复改尺寸。

### G4：不依赖悬停的完整文字

- 五类图、明暗主题和各 preset 中，原始图形已有的节点主标题、说明、副标题、标签／注释和连线文字在初始视图、全图适配及任意有效缩放下均参与绘制。取消 MAP／READ 层级对 `context`／`fine` 文本的自动隐藏，也取消为隐藏副标题而移动主标题的布局补偿。
- 悬停、键盘焦点及语义聚焦可继续高亮、追踪和打开补充信息；进入或离开悬停不能决定某条原有语义文字是否存在。用户主动选择的过滤／聚焦可以按原合同弱化不相关元素，但清除后恢复完整显示。
- 小比例下文字可以随整张图等比变小，不要求所有文字在一屏内都清晰可读；不得用隐藏、删词、缩写、进一步缩小字号或将文字移到 tooltip 来解决拥挤。视野之外的文字仍随图形平移可达。
- 保持原始文案与显式几何，使用原完整详情布局；若发现该布局自身已有碰撞，给出最小复现并修复必要的渲染缺陷，不静默移动作者指定坐标或扩大为自动布局重写。
- 缩放按钮与帮助提示不再宣称“放大后才显示关系标签／注释”。原标签数据属性只有在仍被其他语义、检查或导出合同使用时保留；不额外增加“简洁／详细”切换来绕开新默认。
- G4 是统一读图默认，覆盖普通桌面、窄屏、演示与 embed；这些模式各自的输入和布局合同保持。打印和导出的完整文字合同不变。

## 实施与完成条件

1. **建立真实复现。** 用同一输入和浏览器条件记录基线的页面范围、画布矩形、输入归属和内容末端；区分页面滚动与面板滚动。先补失败的浏览器回归，再调整布局，不能只写静态 CSS 字符串测试。
2. **交付 G1–G4。** 先固定外层尺寸与画布，再迁移说明内容并完成焦点，核对相机、布局测量和兼容模式。G4 在建立文字隐藏复现后可独立实施，最终和新布局一起检查遮挡。权威入口主要为 `viewer/viewer.css`、`template.source.html`、`reader-layout.js`、`viewer-chrome-layout.js`，按必要性影响 Camera／Radar 与 i18n。不预设必须新增模块。
3. **更新合同。** 核对现有 Reader／作者指南的文档流、首屏、卡片与打印描述，在相同范围内更新，保留规范 SVG 和窄屏合同。旧测试仅对明确改变的桌面行为迁移，记录变更依据；不通过放宽全部内容可达性或视觉检查来消除失败。
