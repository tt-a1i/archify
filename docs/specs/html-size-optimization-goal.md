# Goal：缩小独立 HTML，保留完整 Viewer

状态：**已完成。** 用户已授权确定边界、验收并直接实施；A1–A11、候选取舍、实际消融和交付结果见[实施记录](../reviews/html-size-optimization-20260923.md)。改动留在当前本地工作区，未提交或推送。

## 基线和目标

使用当前 `codex/canvas-visual-polish` 工作区（HEAD 01837812 加已完成的画布美化、视角修复、工具互斥）作为基线，不用旧 HEAD 冒充当前交付物。实施前已冻结完整工作区及逐文件 SHA-256。保留全部既有未提交改动。

当前通用模板 843,544 B；同一份 Maka 输入产生 893,011 B 的 HTML。目标：同输入独立 HTML 至少减少 **120 KiB**，五种公共图均缩小；同时没有作者内容、视觉、交互、离线或导出退化。分别报告原始 UTF-8、gzip 和 Brotli 字节；压缩传输不替代原文件目标，不宣称未经测量的运行时提速。

私有 Maka 输入及截图只存本地。公开仓库只收录公共图、代码哈希、聚合统计和检查结果。

## 范围

1. 构建期压缩 JS/CSS：保留可读维护源码，输出紧凑的内嵌 Viewer。使用语法感知的工具，先仅去格式和普通注释；不重命名公开属性、DOM ID、data-* 或 URL 键，不做未经验证的死代码裁剪。字体授权说明保留。
2. 生成期字体子集选择：依据实际静态及动态文案、图文字、标题、说明和证据选择已有 WOFF2 子集。只省略证明无使用字符的子集，不重制字体，不按 locale 武断裁剪。无法确定的自定义模板保留全部字体。
3. 生成期运行时文案精简：只删除已证明仅在生成阶段使用的字典键。保留复数、节点类型和转发错误文案等动态消费者；无法证明的键保留。
4. 同步模板、测试、五类示例、Gallery、相关交付产物与 ZIP；新增体积回归检查和实施证据。

明确排除：轻量版/完整版产品分叉、删除路径/地图/透镜/导出/演示等功能、CDN 或网络依赖、运行时解压器、新设置项、字体风格更换、图形布局调整、schema/版本/发布身份变化、live Skill 安装、提交/推送/发布。

## 保留合同

- 独立 HTML 可从 file:// 离线打开，不发起新增外部请求；打包后的 renderer 不需要安装构建依赖。
- 五种图的节点/边/分组 ID、标签、几何、viewBox、卡片、章节、证据语义保持；输入校验、安全转义和原子写入保持。
- 四 preset、浅深主题、三种语言、响应式/打印/embed/演示保持。
- 路径/地图/透镜互斥；数据库+安全选中状态不重置当前视角或裁掉节点；键盘、焦点、hash 恢复与图例状态保持。
- 字体实际使用字符及字重保持同一 WOFF2 数据；授权、来源说明保留。HTML 与 SVG/栅格/WebM 导出使用一致的字体选择。
- 规范 SVG、PNG/JPEG/WebP、WebM、分享卡、剪贴板导出及清理保持；CSS 压缩不能破坏导出对 CSSOM 规则的筛选。
- 维护源码仍为唯一真源，生成输出可重复、freshness 可检查。构建依赖仅在开发环境安装，明确锁定版本和许可。
