同样的 80 和 100，为什么柱长比例变了？

长图

答

结论

A 是 80，B 是 100；数据没有变化。纵轴从 70 开始后，图中只露出柱子的上面一截，不能用这段长度之比代替数据之比。1

  1. B 与 A 的数值比是 100 / 80 = 1.25，B 比 A 大 25%。
  2. 截断视图中，可见部分分别是 10 和 30，长度比是 3。1

适用于Matplotlib 3.11.2合成的无单位数值正值线性柱状图

1

从零开始：完整柱长

A、B 是两个类别的名称，图上的 Value 意为“数值”。这两个数字是合成示例，没有单位。柱子从 0 开始，可见长度分别对应 80 和 100。1

2

从 70 开始：只看上段

柱子的底部仍是 0，但低于 70 的部分在显示范围之外。A 留下 80 − 70 = 10，B 留下 100 − 70 = 30。1

3

哪个比值回答了什么？

要比较的东西B / A
原始数值100 / 80 = 1.25
从 70 开始露出的柱段30 / 10 = 3

两数相差 100 − 80 = 20；以 A 为基准，差值是 20 / 80 = 25%。可见长度比描述的是被裁切后的图形，不是原始数据比。1

4

改变的是什么？

两张图的柱子底部都是 0，高度仍是 80 和 100。set_ylim 改变纵轴的显示范围，不改变这些柱子属性。23

在这个正值线性柱状图中，显示零点便于把完整柱长与数值对应。局部范围可以帮助查看细节，但应把可见柱段和完整数值分开读。这是对本例的解读，不是所有图表都必须从零开始的规则。
