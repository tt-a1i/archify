# 第一次在大城市租房，签合同前要确认哪些事？ {#first-rent}

核心就三件事：**认准签约的人、看清要住的房、管住付出去的钱**。签字前核实房东身份和产权，把口头承诺逐条写进合同，所有付款和交接都留凭证。

- 先核对身份证和房产证原件，确认签约人有权出租这套房，不轻信口头保证。
- 租金、押金退法、提前退租规则和维修责任，必须在签字前写进合同。
- 钱只转给合同上的出租人并备注用途，拿钥匙当天逐项验房拍照留底。

## 合同里必须写清哪些条款？ {#clauses}

| 条款 | 合同里要写明什么 | 常见踩坑点 |
| --- | --- | --- |
| 租金和收款人 | 月租金额、付款周期、房东本人收款账户 | 要求转给无关第三方账户 {bad:高风险} |
| 押金退还 | 押金金额、退还条件、退房后几天内退回 | 退房时借“深度保洁费”“折旧费”克扣 {bad:高发纠纷} |
| 租期与提前退租 | 起止日期、提前通知天数、违约金上限 | 提前退租直接没收全部押金和剩余房租 {caution:先约定} |
| 维修责任 | 自然老化的家电、水管、电路由房东修并付费 | 入住后大件自然损坏全推给租客买单 |
| 转租与续租 | 中途能否转租、到期续租沟通期及涨租规则 | 既禁止转租，又按高额违约金扣款 |
| 物业与杂费 | 水电气、物业、宽带、取暖各由谁承担 | 前任租客留下的历史欠费算到你账上 |

## 签约当天核对什么？ {#day-of}

@facts id=day-checks
| 房东身份证 | 核对原件，姓名须与房产证一致 |
| 房产证或不动产权证 | 核对房屋地址、产权人姓名及共有情况 |
| 代理人或二房东签约 | 须有产权人亲笔签字的授权委托书或同意转租证明 |
| 首笔付款 | 通常为押一付一或押一付三，金额与收款账号写进合同 |
| 中介费 | 常见为半个月到一个月租金，签约前谈妥并写明退费条件（经验值） |

@callout level=warning title="遇到以下任一红线，直接放弃"
| 不让实地看房就催交定金，或拿不出产权证与转租授权书。要求转入无关私人账户且不给收据，或是刺鼻新装房、违规隔断房，占一条都不要签。

## 拿钥匙交接时查什么？ {#handover}

- [ ] 抄下水表、电表、燃气表读数并拍照留档
- [ ] 打开空调、热水器、燃气灶、洗衣机试运行，冲水试马桶和地漏排水
- [ ] 检查入户门锁、窗户密封、水龙头水压及厨卫有无渗漏
- [ ] 拍下墙面、地板和家具原有划痕破损，当场发给房东留证
- [ ] 清点钥匙、门禁卡、电卡水卡数量并写进交接单
- [ ] 确认前任租客的水电燃气、物业和宽带欠费已全部结清
