第一次在大城市租房，签合同前要确认哪些事？

长图

答

结论

核心就三件事：认准签约的人、看清要住的房、管住付出去的钱。签字前核实房东身份和产权，把口头承诺逐条写进合同，所有付款和交接都留凭证。

  1. 先核对身份证和房产证原件，确认签约人有权出租这套房，不轻信口头保证。
  2. 租金、押金退法、提前退租规则和维修责任，必须在签字前写进合同。
  3. 钱只转给合同上的出租人并备注用途，拿钥匙当天逐项验房拍照留底。

适用于中国大陆城市普通住宅整租或合租首次签约

  1. 实地看房 ↗

    工作日晚上看隔音和采光，周末看周边环境；顺手试水压、手机信号并实测通勤时间。

  2. 核对身份和产权 ↗

    看房东身份证与房产证原件；若是代理人或二房东，必须出示产权人签字的授权或同意转租文件。

  3. 承诺写进合同 ↗

    口头答应的免租期、添置家电、维修分工和退租规则，全部写进合同或补充条款再签字。

  4. 转账并留凭证 ↗

    转账到合同写明的房东本人账户，备注“房租与押金”，并索要收据或在合同上签收。

  5. 逐项验房拍照 ↗

    入住当天拍下水电燃气表读数、家具家电清单和原有破损，当场发给房东确认留档。

合同里必须写清哪些条款？

条款合同里要写明什么常见踩坑点
租金和收款人月租金额、付款周期、房东本人收款账户高风险要求转给无关第三方账户
押金退还押金金额、退还条件、退房后几天内退回高发纠纷退房时借“深度保洁费”“折旧费”克扣
租期与提前退租起止日期、提前通知天数、违约金上限先约定提前退租直接没收全部押金和剩余房租
维修责任自然老化的家电、水管、电路由房东修并付费入住后大件自然损坏全推给租客买单
转租与续租中途能否转租、到期续租沟通期及涨租规则既禁止转租，又按高额违约金扣款
物业与杂费水电气、物业、宽带、取暖各由谁承担前任租客留下的历史欠费算到你账上

签约当天核对什么？

房东身份证
核对原件，姓名须与房产证一致
房产证或不动产权证
核对房屋地址、产权人姓名及共有情况
代理人或二房东签约
须有产权人亲笔签字的授权委托书或同意转租证明
首笔付款
通常为押一付一或押一付三，金额与收款账号写进合同
中介费
常见为半个月到一个月租金，签约前谈妥并写明退费条件（经验值）

遇到以下任一红线，直接放弃

不让实地看房就催交定金，或拿不出产权证与转租授权书。要求转入无关私人账户且不给收据，或是刺鼻新装房、违规隔断房，占一条都不要签。
