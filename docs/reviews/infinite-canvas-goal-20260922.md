## 实现与收益

- **G1 平移入口**：保留右键，增加中键和空格＋左键拖动；画布焦点决定空格归属，抓手光标覆盖 SVG 节点。释放、失焦、取消和捕获丢失都会结束拖动，空格先松开后的延迟点击也不会误触节点。帮助说明覆盖英文、简体中文、西班牙文。
- **G2 适应全部**：独立按钮和 `Archify.view.fitAll()` 按原始 viewBox 与真实可见画布计算等比适配，保留 16 CSS px 安全边距。支持低于 25% 的长／宽图及 `<1%` 显示；适配状态跟随窗口调整，手动导航后退出。百分比按钮、`0`、`reset()` 和旧 `fit()` 的默认视图合同保持。
- **G3 小地图反馈**：手势中只更新镜头、网格、视口和必要的比例文字；结束后合并完整排版及节点扫描。小地图空白定位、拖动和方向键保持当前比例，节点点击仍语义聚焦；关闭小地图释放地图拖动并停止持续写入。

权威实现位于 `viewer/viewer-camera.js`、`viewer/semantic-radar.js`、`viewer/viewer.css`、`viewer/template.source.html`，本地化位于 `archify/renderers/shared/i18n.mjs`。不改 schema、布局算法、拓扑或作者指定几何。

## 消融

1. 删除五个调用点始终与 `interactive` 成对出现的 `cameraOnly`，将轻量更新归入 `interactive` 分支。相同聚焦检查删除前后均为 27 通过、0 失败、9 个浏览器条件跳过；**保留删除**，随后最终真实浏览器门禁通过。
2. 将修复后的 SVG 原点临时换回旧 offset 算法：11 项输入检查中 1 项失败（带内边距的完整适配）；恢复后 11/11 通过。**恢复并保留正确原点计算**，最终浏览器矩阵确认其必要性。
3. 几何缓存有避免每帧布局读取的用途，审查后保留；这项是必要性分析，不宣称做过删除实验。临时同步调用栈调试已删除。

## 历史失败及证据边界

历史结果均对应此前版本，不与本轮结果拼接成一次通过：

- 无 Chrome 的早期完整测试有沙箱监听失败、浏览器跳过和旧 README receipt 失败；不作为最终全绿结果。
- 用户首轮 `CjbkR8`：浏览器 234 通过、4 失败（包含父套件汇总），暴露 SVG 原点与稳态计数前的异步布局未完成。修正原点，计数前等待 Reader／Chrome 公共稳定接口。
- 用户第二轮 `gbsxYX`：定向 18 通过、2 失败（包含父套件汇总）；唯一具体问题为重复适配位置约 0.000016px 的浮点差异。改为 0.001 CSS px 幂等容差；原 2px 内容边界和锚点精度没有放宽，14 个适配组合拆开收集。
- 最终 `Uwc6BE` 结果见上表。内置浏览器的 URL 策略未被更改；浏览器执行来自用户手动启动，agent 只读取结果和检查产物。
