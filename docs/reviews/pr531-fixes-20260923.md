The semantic camera retained a document-mode 100% minimum despite the new fixed canvas using unscaled SVG coordinates. Fixed-canvas chapter fits now allow precise sub-100% scales. Tiny scales are not rounded to zero. Document-mode minimums and Reset remain unchanged.
- **Windows integration probe:** the failed Node 24 PowerShell launch took 5023.86 ms against a 5000 ms timeout; the Node 22 counterpart passed in 2125.98 ms. The timing supports a cold-start timeout hypothesis, but the old assertion discarded the child-process error, so the exact error is unproven. The real-launch test now uses a 30-second startup budget and includes elapsed time, timeout, error code, exit status, and signal on failure. Production's five-second default and timeout failure behavior are unchanged and remain independently tested.

It now awaits the Reader and Chrome Layout stability contracts before measuring the drag origin and includes camera/legend geometry in failure diagnostics. The existing two-pixel coordinate tolerance and overlap assertions are unchanged. The original failure did not reproduce locally; layout timing is the working explanation, not a proven root cause.
- **Review evidence:** actual Git-base renders now accompany candidate screenshots for all five public diagram types and the document fallback. The earlier baseline with local changes is no longer the only comparison.

No workflow, dependency, version, schema, topology, or production opener changes were required.
