## 实现与边界

`scripts/generate-viewer.mjs` 在既有片段拼装完成后，通过锁定的构建期依赖 `esbuild@0.28.2` 压缩两个普通 script 块及主 style 块。仅启用 minifyWhitespace，显式关闭 identifier/syntax minification 和 tree shaking，保留 legal comments 和 UTF-8。

可读源码仍在 viewer/。经典脚本的执行顺序、作用域和公开 API 保持；模板 HTML 槽位及带完整许可的字体块没有进入压缩过程。没有新增浏览器请求、CDN、运行时解压器、source map、产品开关或轻量版。打包器剥离开发依赖，包外 renderer 仍无需 node_modules。

维护成本新增一个锁定的构建依赖和一个测试专用源码合同辅助器；没有新增交付运行时依赖或第二份维护源码。

所用构建选项可核对 [esbuild 官方 API](https://esbuild.github.io/api/#minify)。版本被锁文件固定，不让不同开发机自行选择压缩器版本。

不少旧测试用源文本的空格、注释标题和缩进定位逻辑。新的测试辅助器先严格验证实际交付块等于权威源码编译结果，再向这类源结构断言提供可读源码；修改编译块会使验证失败。原断言保留，未以删除断言过关。真实浏览器始终加载压缩后的磁盘产物，测试专用注入锚点改为允许空白差异的窄匹配。

## 候选取舍

| 候选 | 可达性与必要性证据 | 决策 |
|---|---|---|
| 交付 JS/CSS 中的普通注释和冗余排版 | 维护由原源码承担；编译器处理语法边界、必要分隔与内联脚本转义 | 实施，净省 187.5 KiB |
| 非初始图文字所需字体子集 | Finder 输入任意文字且继承相同字体；已有离线字体验收会加载图初始内容以外的 Latin 扩展、Greek、Cyrillic、Vietnamese 字符 | 保留六个子集。静态字表不能封闭实际使用字符，不牺牲离线覆盖换体积 |
| 运行时字典里的仅静态使用键 | applyTemplate 支持自定义模板；运行时可构造完整文案键，缺少可证明的封闭消费者清单。候选节省仅约 5.6 KiB | 保留完整当前语言目录；增加三语言完整性/动态键保留回归，不增加标记、键索引或产品版本分叉 |
| 导出、Story、路径、地图、透镜模块 | 均有实际消费者与本轮要求保留的能力 | 不删除 |
| 共享外部 Viewer、运行时解压器 | 单文件离线交付不需要这些额外运行时和网络责任 | 不引入 |

这符合 Goal 的“无法证明安全或净收益不足则保留候选”边界。最终收益全部来自已经验证的压缩，不把字体和语言包候选上限加入节省量。

### 基线失败与测试修正

后续 PR #542 审核发现下述嵌入投影断言使用了错误类名，空集合使其误通过；产品行为未复现回归。现已修正真实选择器并增加数量断言，重新通过完整 WebM/语言门禁和负向探针。原阶段日志保留其历史身份；更正证据见[修复记录](pr542-embed-assertion-fix.md)。

WebM smoke 的嵌入模式图例计数断言在冻结的未压缩基线上同样失败：先前固定图例实现保留了隐藏 DOM 投影，旧断言查询整个 document 因而重复计数。此次修正为检查主 SVG 的作者图例，并新增断言要求固定投影 hidden、display:none 且没有 tab stop；保留原来的零交互角色/零运行时徽章要求。没有为此修改产品行为。修正后完整 WebM smoke 和语言集成通过。

公共浏览器门禁未配置私有输入，因此总数为 393；前轮额外的六个私有架构首屏场景已通过单独配置的 46 项取景套件补齐，不重复计入公共门禁总数。

与冻结基线比较，49 个 Viewer 运行时和 renderer 文件保持字节一致。

其他中间失败来自依赖源排版的断言/夹具和待更新的生成产物；最终门禁记录单列，不将中间运行当作最终通过。
